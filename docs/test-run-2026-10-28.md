# Test run: four sites (2026-10-28)

Behindsight ran on elementor.com, monday.com, allbirds.com and gong.io. A fresh agent per site followed SKILL.md, wrote findings that passed the citation check, and logged every problem it saw in the collected data or the instructions. About 140 gaps came back. These were fixed:

| Area | Problem | Fix |
|---|---|---|
| Wappalyzer | Crashed on 4 of 5 Elementor pages, so WordPress and Elementor itself were missing | `setup.sh` patches the fork to skip unknown detections |
| Stack | Missed tools: Intellimize, Bizible, Dreamdata, MadKudu, CHEQ, OpenAI Ads pixel, Triple Whale, Elevar, GovX, Shopify, Weglot, Descope, Turnstile, Impact custom domains | New signatures |
| Stack | Marketo forms and Statsig served from the company's own domain; a GA4 URL falsely matched Statsig | Path and query patterns, checked separately |
| Stack | Known vendors' other hosts listed as unrecognized | Vendor domains are excluded from that list |
| Stack | No view of WordPress plugins | Plugin and theme slugs from asset paths |
| Events | Only GA4 and Meta GET events | Meta POST, Pinterest, Reddit, TikTok, Google Ads conversions |
| Pages | Sites got 2 to 6 pages instead of 7; no store pages | Store page kinds (collections, our story), blog index, nav pages fill empty slots |
| Pages | Requests logged against the pre-redirect URL | Relabeled with the final URL |
| Sitemap | Sections in their own sitemaps (Elementor's /blog/) missed | Subfolder sitemaps are tried |
| Sitemap | Duplicate URLs inflated counts (14,035 vs 7,664 unique) | De-duplicated |
| Sitemap | Locale folders below the first level (/blog/fr/) missed; comparison count mixed in blog posts | Locales in the first two folders; comparison pages and comparison posts counted separately |
| Search | Branded share inflated by common words ("mondays", "gong") | Whole-word and near-spelling matching; share also shown without the bare brand name |
| Search | Competitors were publishers (archive.org, quora topics) | Seeds from keywords landing on selling pages, or a second query outside blog and resources; overlap of 2 or more, ranked by overlap |
| Ads | Meta and LinkedIn counted the US only (Allbirds: 2 US, 85 worldwide) | Worldwide counts too; ad copy read worldwide |
| Ads | Google screenshots in Tagalog, error pages saved as samples, duplicate images | `hl=en`, status check, hash de-duplication |
| Ads | Meta footer text read as a headline; body text as the CTA | Footer cut off; CTA only when short |
| Checker | "2,114" and "180K+" misread; prices split across lines; "last 30 days" read as a statistic | Fixed number and quote parsing |
| Checker | Numbers in claim text never checked; image-only ad copy couldn't be cited | Warning-level check on claim numbers; `ads/<file>` refs |
| Instructions | Scope section out of date; nothing for e-commerce; `verify.json` undocumented | SKILL.md, schema and inference guide updated |

Still open: animated counters read as digit reels, multi-step forms show only the first step, the capture region follows the machine running it, and Pinterest, Reddit and TikTok ad libraries aren't read.
